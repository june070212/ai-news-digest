# AI News Digest

A static digest of **GitHub** and **Microsoft** developer news — pulled from public
RSS feeds, de-duplicated, ranked by importance, and published to GitHub Pages.

**Live site:** https://june070212/ai-news-digest/

## How it works

GitHub Pages serves static files, and the upstream feeds don't send CORS headers,
so the digest is **prerendered at build time**:

1. `scripts/build-digest.mjs` fetches every feed, parses RSS 2.0 and Atom,
   de-duplicates across sources, scores each story, and writes
   `assets/data.json`.
2. The GitHub Actions workflow runs that script, then publishes the repo root
   via the official Pages actions.
3. `assets/main.js` loads the JSON and renders the page — filtering, search, and
   sorting all happen client-side.

If every feed fails, the build exits non-zero rather than publishing an empty
digest, so the last good digest stays live.

Ranking is deterministic — no model in the loop. Stories earn points for source
weight, AI and shipping vocabulary, breaking-change signals, a Copilot bonus, and
recency; the score maps to a high / medium / low badge.

## Run locally

```sh
node scripts/build-digest.mjs   # writes assets/data.json
python3 -m http.server 8000     # then open http://localhost:8000/
```

Requires Node 18+ (for global `fetch`). No dependencies, no build step.

Environment overrides: `DIGEST_DAYS` (default `14`), `DIGEST_LIMIT` (default
`60`), `FEED_TIMEOUT_MS` (default `12000`).

The deployed site sets `DIGEST_DAYS=3` in the workflow so it shows only recent
news; a local run without that override looks back further and returns more
stories.

## Deploy

> **Re-homing the repo?** Run `node scripts/set-owner.mjs <new-owner>` first — it
> rewrites the canonical/OG URLs and source links. The site's own links are all
> relative, so nothing else needs changing.

1. Push to the repo's `main` branch.
2. **Settings → Pages → Source → GitHub Actions**.
3. `.github/workflows/deploy.yml` runs on every push to `main`, twice daily on a
   cron, and on demand via **Run workflow**.

## Structure

```
index.html                     Digest: metrics, TL;DR, filters, story list, sources
about.html                     How the collection and ranking work
404.html                       Custom not-found page
assets/
  styles.css                   Styling + light/dark theme tokens
  main.js                      Rendering, filtering, search, sort, theme toggle
  data.json                    Prerendered digest (regenerated by CI)
  images/                      Logo, social card, favicon, hero (+ IMAGES.md)
scripts/
  build-digest.mjs             Build-time digest generator
  set-owner.mjs                Repoint absolute URLs at a different GitHub owner
  feeds.mjs                    Feed list, RSS/Atom parser, scoring, de-duplication
  net.mjs                      Allow-listed, timeout-bounded fetch
.nojekyll                      Serve files as-is (skip Jekyll)
.github/workflows/deploy.yml   Build + Pages deploy workflow
```
